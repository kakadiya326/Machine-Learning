# Student Performance Prediction

## 📌 Overview
A machine learning project to analyze and predict student performance using regression techniques.

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn

## 🚀 Features
- Data cleaning
- Exploratory Data Analysis (EDA)
- Model training
- Performance evaluation

## ⚙️ Workflow
1. Load dataset
2. Clean and preprocess data
3. Perform EDA
4. Train model
5. Predict performance

## 📊 Metrics
- R² Score
- MAE
